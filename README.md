# Todo-List Testing

Тестовая документация для веб-приложения «Список задач» (Todo-List).

## Структура
- `requirements.md` — требования.
- `test-cases/` — 15 тест-кейсов.
- `test-suites/` — пять тестовых пакетов.
- `test-run/run-report.md` — отчёт о прогоне.
- `bug-reports/` — два учебных баг-репорта.
- `coverage/coverage-report.md` — матрица покрытия требований.

**Важно:** тест-кейсы подготовлены, но не запускались на реальном приложении. Примеры баг-репортов требуют подтверждения.

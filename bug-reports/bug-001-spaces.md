# BUG-001. Задача из пробелов добавляется
**Тест:** [TC-003](../test-cases/tc-003-whitespace-task.md) · **Приоритет:** Средний · **Статус:** требует проверки
## Шаги
1. Ввести несколько пробелов.
2. Нажать «Добавить».
## Ожидаемый результат
Задача не добавляется.
## Фактический результат
Учебный пример: запись с пустым текстом добавляется.
> Дефект не подтверждён реальным запуском.

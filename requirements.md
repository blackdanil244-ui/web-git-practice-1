# Требования к Todo-List

| ID | Требование | Критерий приёмки |
|---|---|---|
| REQ-01 | Добавление; пустая задача не добавляется | Пустая строка и строка из пробелов не создают задачу |
| REQ-02 | Максимум 200 символов | 200 принимаются, 201-й не принимается |
| REQ-03 | Отметка выполненной | Статус переключается |
| REQ-04 | Редактирование текста | Текст сохраняется; Escape отменяет изменение |
| REQ-05 | Удаление задачи | Выбранная задача исчезает |
| REQ-06 | Фильтры Все / Активные / Выполненные | Отображается выбранная категория |
| REQ-07 | Очистка выполненных | Удаляются выполненные, активные остаются |
| REQ-08 | Сохранение после перезагрузки | Задачи и статусы восстанавливаются |
| REQ-09 | Счётчик активных | Показывается число невыполненных задач |
| REQ-10 | Адаптивность от 320 px | Элементы доступны при viewport 320 px |
